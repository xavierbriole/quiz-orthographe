Quiz Langues is a personal tool that automatically creates short educational quiz videos for language learners: French spelling, Chinese vocabulary (for English speakers) and French vocabulary (for Chinese speakers). Each video shows a few words with three possible answers, a countdown, and the correct answer.

The tool uses the TikTok Content Posting API to send each finished video as a draft to the creator's own TikTok inbox. The creator then reviews, edits and publishes the video manually in the TikTok app. Nothing is ever published automatically.

How it works

  1. Once a day, a server generates a new video for each quiz.
  2. The video is uploaded as a draft to the operator's own TikTok account for that quiz (scope video.upload).
  3. The operator opens the TikTok notification, reviews the draft and decides whether to publish it.

This tool is operated by Xavier Briole for his own TikTok accounts only. It is not offered to other users.
